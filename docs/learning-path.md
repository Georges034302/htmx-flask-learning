# Learning Path

## Recommended Order
Follow lessons strictly in numeric order from [lessons/index.md](../lessons/index.md).

## Phase Breakdown
1. Foundation (01-12)
- Environment setup, Flask baseline, first HTMX interactions

2. Interactive CRUD and Table UX (13-25)
- Row actions, inline editing, filtering, sorting, pagination

3. UX and Feedback Systems (26-32)
- Flash messaging, auto-dismiss, polling, modal workflows

4. Data and Validation (33-34)
- SQLAlchemy integration path and server-side validation strategy

5. Application Features (35-36)
- Authentication and file upload workflows

6. Production and Operations (37-41)
- Docker, Azure deployment, CI/CD, WSGI tuning, environment config

## Practical Rule
- Do not skip forward before passing each lesson's test/check section.
- If a lesson is marked instructions-only, treat it as a design/implementation blueprint.
