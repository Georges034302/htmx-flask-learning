# Learning Path

## Recommended Order

Follow modules strictly in numeric order from [index.md](index.md).

## Phase Breakdown

| Phase | Modules | Focus |
|-------|---------|-------|
| 1 | 01–02 | Environment setup, Flask baseline, first HTMX interactions |
| 2 | 03–04 | Flask architecture, Blueprint structure, full CRUD |
| 3 | 05 | Search, filtering, sorting, pagination |
| 4 | 06 | Flash messaging, auto-dismiss, polling, modals |
| 5 | 07 | Progressive enhancement, OOB swaps, clean route design |
| 6 | 08 | SQLAlchemy, form validation, MySQL integration |
| 7 | 09 | Session-based auth, file uploads |
| 8 | 10 | Docker + Gunicorn, Azure Key Vault, Container Apps, AKS/Helm, GitHub Actions CI/CD, Azure DevOps CI/CD |

## Practical Rules

- Do not skip forward before completing each lesson's check section.
- Lessons marked instructions-only are design/implementation blueprints — apply them in your own working project.
- Modules 08–10 depend on external infrastructure (database server, cloud subscription, CI secrets, container runtime).
