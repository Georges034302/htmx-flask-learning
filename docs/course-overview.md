# Course Overview

## Purpose
This repository is a structured learning curriculum for building a server-driven web application with Flask and HTMX.

## Scope
- Build a full CRUD-style employee dashboard from first principles
- Learn progressive UX patterns without a frontend framework
- Advance into authentication, uploads, and production/deployment topics

## Course Shape
- Total modules: 48
- Core implementation track: modules 01-32, 35-36, 42-44
- Advanced instructions track: modules 33-34, 37-41, 45-48

## Primary Entry Points
- Curriculum index: [docs/index.md](index.md)
- Repository overview: [README.md](../README.md)

## Expected Outcomes
By completing the course, a learner should be able to:
- Build reactive server-rendered interfaces with HTMX
- Structure Flask apps with maintainable route and template patterns
- Implement practical UI behaviors (search, sorting, pagination, flash feedback)
- Use template inheritance to eliminate duplicated HTML across pages
- Apply progressive enhancement so every URL works with direct browser navigation
- Use out-of-band swaps to update multiple page regions in a single response
- Transition from mock data to SQLite and then MySQL-backed workflows
- Design resource-based routes and scale to multiple Flask Blueprints
- Deploy to both Azure Container Apps and Render
- Make informed decisions about when HTMX is (and is not) the right tool
